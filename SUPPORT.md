# Support

Before opening an issue:

1. Upgrade to the latest release.
2. Run `cfetch selfcheck`.
3. Check the README and existing issues.
4. Remove secrets and private brain content from all output.

Use the repository's structured issue forms:

- **Bug report** for reproducible incorrect behavior.
- **Feature request** for a problem the product does not yet solve.
- **Question** for installation, configuration, or usage help.

Include `cfetch --version`, `cfetch variants --json`, the operating system,
agent harness, and relevant redacted `cfetch selfcheck` output. Support covers
the latest release; older releases may be closed with an upgrade request.

Suspected vulnerabilities do not belong in the issue tracker. Follow
[SECURITY.md](SECURITY.md) instead.
